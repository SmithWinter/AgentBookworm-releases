# Agent Bookworm releases

Downloads and update feed for **Agent Bookworm**, the Mac app that keeps your Safari, Chrome, Brave, Edge and Arc bookmarks in one encrypted library and cleans out the duplicates.

- **Download:** grab the DMG from the [latest release](https://github.com/SmithWinter/VibeBookworm-releases/releases/latest), open it and drag Agent Bookworm into Applications.
- **Updates:** Agent Bookworm checks `appcast.xml` in this repo through Sparkle, so installed copies update themselves. Staging builds read `appcast-staging.xml`.

The source code lives in a private repository. This repo only carries the signed builds.
